# Knowledge base

The `policies/` directory contains fictional motor policy documents for retrieval and claim-analysis learning exercises:

- `motor_comprehensive.md` describes broader synthetic vehicle-damage protection.
- `motor_standard.md` describes narrower synthetic protection for specified events.

These documents represent no real insurer or product and are not legal, financial, or insurance advice. Individual policy values such as limits and deductibles are intentionally not included; they belong to the policy record in PostgreSQL.
